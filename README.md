# Python Programming

Structured Python learning path organized into chapters, progressing from syntax basics to file handling, OOP, and mini-game projects.

## Chapters

| Chapter | Topic |
|---------|-------|
| 01 | Introduction, variables, data types |
| 02 | Strings and string methods |
| 03 | Numbers, math operations, type conversion |
| 04 | Lists, tuples, sets |
| 05 | Dictionaries and data structures |
| 06 | Conditionals (if, elif, else) |
| 07 | Loops (for, while) and iterations |
| 08 | Functions and modules |
| 09 | File handling (read, write, append) |
| 10 | Error handling (try, except, finally) |
| 11 | Object-Oriented Programming |
| 12 | Advanced topics |

## Projects

| Project | Description |
|---------|-------------|
| `project-01` | Number guessing game |
| `project-02` | Rock Paper Scissors game |

## Run

```bash
python chapter-01/filename.py
```
